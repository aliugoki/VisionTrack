# YOLOv8 person detector — single-class, prebuilt engine
#
# Replaces the PeopleNet config because:

#
# Output tensor confirmed via trtexec:
#   Input:  images       1x3x640x640
#   Output: output0      1x5x8400   (cx, cy, w, h, person_conf × 8400 proposals)
